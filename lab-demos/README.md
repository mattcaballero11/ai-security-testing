# Lab Demonstrations (moved)

This directory used to be the planned home for hands-on exploitation write-ups. That work now lives in two places instead of one, because a single "demos" folder next to a "scenarios" folder was confusing.

- [scenarios/](../scenarios/) holds the threat model, precondition, attack, and success criterion for each scenario.
- [findings/](../findings/) holds the finding write-up: observed result, trial count, severity, and residual risk.

Nothing has been published in either yet. See the scenario status table in [README.md](../README.md) for what is actually built.

This directory will be removed once scenarios/ and findings/ are populated. It stays for now only so a link into the old path does not 404.
